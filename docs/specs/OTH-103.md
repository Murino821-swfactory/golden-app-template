## Approach
Implement pure client-side CV import capabilities for PDF/DOC/DOCX files and LinkedIn profiles:
1. **Parser Engine (`lib/cv-import.ts`)**:
   - `extractTextFromFile(file: File)`:
     - Plain text (`.txt`): read directly via `FileReader.readAsText()`.
     - Word document (`.docx`): read binary zip archive using `FileReader.readAsArrayBuffer()` and extract text from `word/document.xml` nodes using `DOMParser`.
     - PDF (`.pdf`) & DOC (`.doc`): read binary data via `FileReader`, extracting readable ASCII/UTF-8 text streams with clean whitespace normalization. If unreadable, fallback with helpful user error feedback.
   - `parseLinkedinProfile(input: string)`:
     - Detects LinkedIn profile URL (e.g. `https://www.linkedin.com/in/username`) or raw profile export text.
     - Parses profile handle/URL or structured text (Headline, Summary, Experience, Skills) into formatted CV text sections.
2. **UI Integration (`components/features/cv-matcher.tsx`)**:
   - Add an "Import CV" action bar above or inside the CV panel with:
     - **File Upload Button / Dropzone**: Accepts `.pdf`, `.docx`, `.doc`, `.txt`. Triggers hidden file input on click or supports drag-and-drop.
     - **LinkedIn Import Button**: Opens a modal/dialog with input for a LinkedIn Profile URL or profile text export.
   - Upon successful import, automatically populates the `cv` textarea, updates word counts, and triggers live match analysis.
3. **Copy Centralization (`lib/cv-matcher-copy.ts`)**:
   - Add localized UI labels for EN and SK: "Import CV", "Upload PDF / DOCX", "Import LinkedIn", modal labels, dropzone hints, success toast/notice ("CV imported successfully from file.pdf"), and error fallback messages.

## Risks & Mitigations
- **Risk**: Complex binary PDF files with custom encodings or encryption cannot be read cleanly via client-side regex string parsing.
  - **Mitigation**: Provide clean text stream decoding fallback and display a user-friendly message if extracted text is under 10 words, prompting user to copy-paste as plain text if needed.
- **Risk**: Direct CORS restrictions prevent browser fetching of external `linkedin.com` web pages.
  - **Mitigation**: Handle LinkedIn URLs by client-side parsing the handle/URL into structured profile sections and allow raw text paste from LinkedIn PDF exports or profile text directly in the modal.

## Edge Cases
- [ ] User drops an unsupported file type (e.g. `.png` or `.exe`): Displays localized file type error message without crashing.
- [ ] User imports an empty file or a file containing 0 words: Displays notification asking for a valid document.
- [ ] User inputs a LinkedIn URL with trailing query parameters or custom subdomains: Cleanly parses the profile handle and generates formatted profile text.
- [ ] File import performed while text exists in CV panel: Overwrites CV text cleanly and triggers live score re-analysis.
